# Reproducible Evaluation

The original `45%`, `35%`, and `22%` values are unsupported. They must be
removed from the resume until the following experiment is run with real service
credentials and reviewed outputs.

## Prepare the stack

```bash
docker compose up -d redis qdrant
python scripts/seed_knowledge.py \
  --dir data/knowledge_base \
  --strategy semantic \
  --chunk-size 1000 \
  --overlap 100
```

## Run a baseline

Configure the baseline implementation (buffer memory, dense retrieval, no
source ranking), then run:

```bash
mkdir -p benchmark-results
python scripts/benchmark.py \
  --questions data/evaluation/questions.json \
  --runs 3 \
  --output benchmark-results/baseline.json
```

## Run the candidate

Enable summary memory, hybrid retrieval, deduplication, and source ranking, then
run the same dataset:

```bash
python scripts/benchmark.py \
  --questions data/evaluation/questions.json \
  --runs 3 \
  --output benchmark-results/candidate.json

python scripts/compare_benchmarks.py \
  benchmark-results/baseline.json \
  benchmark-results/candidate.json \
  --output benchmark-results/comparison.json
```

Each run records the selected prompt name and version. To review production
feedback before creating a candidate prompt:

```bash
python scripts/analyze_feedback.py \
  --output benchmark-results/feedback-analysis.json
```

Create a new prompt version only after reviewing negative examples. Set
`PROMPT_VERSION` for the candidate run, compare it against the unchanged
baseline, and promote it only when quality does not regress and latency/token
cost remain acceptable. Feedback never edits a live prompt automatically.

## Metrics

- `term_recall`: expected answer terms found divided by labeled terms.
- `hallucination_rate`: forbidden claims found divided by labeled forbidden claims.
- `factuality_proxy`: term recall multiplied by one minus hallucination rate.
- `recall_at_k`: expected sources retrieved divided by labeled expected sources.
- `reciprocal_rank`: inverse rank of the first expected source.
- `P50/P95`: median and 95th-percentile successful request latency.

These deterministic metrics are useful for regression testing, not a substitute
for a larger human-reviewed evaluation. Before using a percentage on a resume,
expand the dataset, report sample size and variance, inspect raw answers, and
retain both JSON artifacts.
